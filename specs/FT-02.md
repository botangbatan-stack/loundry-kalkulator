# FT-02 Input Berat & Notifikasi Min. Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 7 (Main User Flow), Bagian 8 (AC-01), Bagian 9 (TC-01, TC-03), Bagian 11 (Configuration Data Reference)

## Tujuan
Pengguna dapat mengisi perkiraan berat cucian dalam kilogram, melihat apakah aturan minimum 3 kg berlaku, dan mengetahui subtotal biaya layanan utama sebelum memilih layanan tambahan.

## Alur
1. Dari Langkah 1 (`Pilih Layanan`), pengguna menekan tombol `Lanjut Isi Berat` dan masuk ke Langkah 2 (`Berat`).
2. Pengguna melihat paket layanan yang dipilih beserta kolom input perkiraan berat cucian yang awalnya kosong.
3. Pengguna mengetik perkiraan berat (memakai koma atau titik, misalnya `2,5` atau `2.5`).
4. Jika berat yang dimasukkan berada di antara `0,1` kg hingga kurang dari `3` kg, sistem langsung menampilkan notifikasi visual bahwa ketentuan minimum 3 kg berlaku sehingga berat ditagih menjadi `3` kg.
5. Sistem langsung menghitung berat ditagih dan menampilkan subtotal biaya layanan utama secara otomatis.
6. Saat pengguna menekan tombol utama untuk melangkah ke tahap berikutnya, sistem memeriksa validitas berat; jika masih kosong atau kurang dari `0,1` kg, sistem menampilkan pesan error dan memindahkan fokus ke kolom berat.

## Data
- `STORE_INFO.minimumChargeKg` (`3.0`)
- `UI_CONFIG.weightStepKg` (`0.1`)
- `UI_CONFIG.minWeightInputKg` (`0.1`)
- `MAIN_SERVICES` (tarif per kg dari layanan terpilih)

## Aturan dan rumus
- Satuan input dan perhitungan adalah kilogram (`kg`).
- Pengguna boleh mengetik koma (`,`) atau titik (`.`) sebagai pemisah desimal; spasi di awal dan akhir teks dihapus sebelum diproses.
- Jika angka memiliki lebih dari satu angka di belakang koma, nilai dibulatkan ke kelipatan `0,1` kg terdekat (`Math.round(nilai * 10) / 10`).
- Rentang nilai valid: berat aktual $\ge 0,1$ kg (tidak boleh kosong, `0`, atau minus).
- Rumus berat ditagih (`BL-01`):
  `beratDitagih = Math.max(STORE_INFO.minimumChargeKg, beratAktual)`
- Rumus biaya layanan utama:
  `biayaUtama = Math.round(beratDitagih * tarifLayanan)`
- Aturan notifikasi minimum charge:
  - Jika `beratAktual >= 0.1` dan `beratAktual < STORE_INFO.minimumChargeKg`, tampilkan notifikasi bahwa minimum charge `3 kg` diberlakukan.
  - Jika `beratAktual >= STORE_INFO.minimumChargeKg`, notifikasi minimum charge tidak ditampilkan.
- Tampilan angka desimal memakai koma tanpa nol di belakang (contoh: `4,5` dan `3`), sedangkan Rupiah tanpa spasi setelah `Rp` (contoh: `Rp18.000`).

## Input dan validasi
- **Kolom Perkiraan Berat Cucian (`weight`):**
  - Status: wajib diisi agar dapat melanjutkan dari Langkah 2.
  - Atribut HTML: `type="text"`, `inputMode="decimal"`, `name="weight"`, label selalu terlihat.
  - Aturan valid: setelah spasi awal/akhir dihapus dan koma diubah ke titik, nilai harus berupa angka valid $\ge 0,1$.
  - Pesan error jika tidak valid (misalnya kosong, `0`, negatif, atau huruf): `"Masukkan berat minimal 0,1 kg, contoh: 2,5."`
  - Jika error muncul saat tombol aksi ditekan, fokus langsung dipindahkan ke kolom berat.

## Tampilan dan teks
- Judul bagian: `Berat Cucian`
- Label kolom: `Perkiraan berat cucian (kg)`
- Teks bantuan di bawah kolom: `Isi angka dalam kg, contoh 2,5 atau 4.`
- Notifikasi minimum charge (saat `0,1 <= berat < 3`): kotak status amber (`bg-amber-50 text-amber-800`) dengan ikon informasi dan teks: `Ketentuan minimum 3 kg berlaku. Berat ditagih menjadi 3 kg.`
- Ringkasan hasil pada langkah ini (saat berat valid): menampilkan `Berat ditagih: [Y] kg` dan `Biaya layanan utama: Rp[Subtotal]`.
- Kolom input berat memakai input angka desimal dengan tombol cepat `-` dan `+` sebesar `±0,5 kg` di sampingnya (keputusan pengguna: pilihan A).
- Bar bawah tetap menempel menampilkan subtotal terkini dan tombol `Lanjut ke Pemesan` serta tombol `Kembali` ke Langkah 1.
